# Publishing a new challenge

The site is generated by `build.py` (Python 3 stdlib only) from `challenges/*.md` and deployed to GitHub Pages
by `.github/workflows/pages.yml` on every push to `main`. Adding a challenge = add one markdown file + push.

## 1. File name
`challenges/NNN-slug.md` — `NNN` is the next zero-padded number (e.g. `004`), `slug` is lowercase `a-z0-9-`.
The URL becomes `https://dailyvibechallenge.github.io/challenges/NNN-slug/`.

## 2. File format (follow exactly)
````markdown
---
date: 2026-10-15
---
# #004 — Title Here
**Difficulty:** Beginner · **Time:** 1–2 hours · **Theme:** AI agents

## Description
One paragraph (used as meta description, feed summary and card text).

## Starter Prompt
```
The full copy-paste prompt. (Must be the first fenced code block under "## Starter Prompt".)
```

## Success Criteria
- ...

## Optional Extensions
- ...
````
- `date` (YYYY-MM-DD) is optional; if omitted the git commit date of the file is used. The newest date (then highest number) is shown on the home page as "Latest challenge".
- Optional front-matter key `description:` overrides the Description paragraph for SEO.
- Never put personal names/emails in challenge files.

## 3. Commands for the daily job
```bash
cd /workspace/daily-vibe/site
git pull --rebase origin main
cp /path/to/new/004-my-slug.md challenges/      # or write it directly
python3 build.py                                 # local sanity check; must print "Built N challenges"
git add challenges/
git commit -m "Add challenge #004: Title"
git push origin main
# optional: wait for deploy and verify
gh run watch "$(gh run list --workflow pages.yml -L1 --json databaseId -q '.[0].databaseId')" --exit-status
curl -fsS -o /dev/null -w '%{http_code}\n' https://dailyvibechallenge.github.io/challenges/004-my-slug/
```
Git identity is configured locally in this repo (Daily Vibe Challenge / noreply address) — do not change it.

## What gets regenerated automatically
Home, challenge page (with Copy prompt button), raw `.md` copy, archive, about, `feed.xml` (Atom), `sitemap.xml`,
`robots.txt`, `llms.txt`, `llms-full.txt`, `challenges.json`, JSON-LD (WebSite + HowTo per challenge), OG/Twitter tags.

## Newsletter
The newsletter block (Buttondown embed form, username `dailyvibe`) is the `NEWSLETTER` constant in `build.py`, shown on home, challenge and about pages.

## Manual redeploy
`gh workflow run pages.yml` (or push any commit).
